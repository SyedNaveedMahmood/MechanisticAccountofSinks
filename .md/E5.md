# E5 — Evaluation Robustness & the Functional Cost of Sink Removal

**Experiment documentation: evaluation-robustness harness, statistical analysis, and run protocol.**
Branch: `E5_Implimentation` (off `E3-E4`). Driver: `evaluation_robustness_analysis.py`.

This document describes the production implementation of E5 for the BlackboxNLP 2026
Reproducibility Track. E5 asks whether the paper's mechanistic conclusions survive changes in
measurement, context length, and content, and what language-model function is lost when a sink is
removed. It extends—not replaces—the validated E3/E4 harnesses.

> **Implementation-status note.** Smoke, parity, fidelity, GPU, reduced, and full experimental
> checks are implemented, but none were executed during the coding task that created E5. Only
> non-experimental source checks were permitted. Do not describe E5 as experimentally validated
> until the commands in §12 have been run and their cached outputs inspected.

---

## 1. Scientific motivation

The source paper evaluates ten interventions using one pooled number: mean attention received by
position 0 from second-half queries in GPT-2 layers 4–11, on 40-token sequences. That design cannot
show whether conclusions depend on a particular metric, whether the fixed-logit mechanism scales
to the 1024-token context, or whether suppressing a sink harms next-token prediction. E5 adds:

1. a metric multiverse and head-level intensive/extensive analysis;
2. paired nested-prefix length generalization and a quantitative logit-competition law;
3. a sink-removal-versus-cross-entropy mitigation frontier;
4. dataset-free content controls and optional multilingual stress tests; and
5. bootstrap/reseed calibration plus paired minimum-detectable-effect estimates.

### Pre-registered hypotheses

| ID | Prediction |
|---|---|
| **H-M1** | Sink-strength intervention rankings are concordant across metrics (target Kendall τ ≥ 0.8). |
| **H-M2** | Circuit interventions primarily shrink active sink cells continuously (intensive margin), rather than killing a subset only (extensive margin). |
| **H-C1** | Surgical circuit interventions Pareto-dominate coarse No-MLP and No-PE ablations in sink reduction per nat of CE damage. |
| **H-C2** | Functional damage is concentrated at later positions and increases at long context. |
| **H-D1** | Baseline and surgical intervention signatures remain close to natural text on random, shuffled, repeated, and multilingual content; coarse interventions may drift more. |

Either polarity is reportable. The code does not encode expected numeric outcomes.

## 2. Metric definitions and directionality

All metrics consume the same selected-band attention maps. For GPT-2 small, default `scaled` mode
selects zero-indexed `[3,11)`, the paper's 1-indexed layers 4–11. The second half begins at
`floor(sequence_length/2)`.

- **`bos_attn`**: mean attention to key position 0 over selected layers, all heads, and all
  second-half query rows. Larger means a stronger sink and matches Table 1.
- **`sink_rate_0_2`, `sink_rate_0_3`, `sink_rate_0_5`**: fraction of selected `(layer, head)` cells
  whose mean second-half BOS mass is greater than 0.2, 0.3, or 0.5. Larger means stronger/more
  prevalent sinks.
- **`attn_entropy`**: Shannon entropy of each second-half row over causally valid keys `0..q`,
  normalized by `log(q+1)`, then averaged. Zero probabilities are handled without `log(0)`.
  Lower values are oriented as stronger concentration for ranking analysis.
- **`bos_rank`**: position 0's competition rank among causal keys. Rank is
  `1 + count(probability strictly greater than BOS probability)`. Ties receive the same best rank;
  lower rank means a stronger sink.
- **Redistribution**: raw mass on positions 1–4, raw mass on positions 5+, and the local share
  `mass(1:4)/(mass(1:4)+mass(5+))`. Empty ranges contribute zero, so short sequences are valid.
- **`head_gini`**: Gini concentration of per-cell mean BOS mass. A zero-total grid has Gini 0.

`METRIC_ORIENTATION` converts only direct sink-strength metrics to a common ranking direction:
`bos_attn` and sink rates use `+1`; rank and entropy use `-1`. Raw values are always preserved.
Gini and redistribution are structural metrics and are excluded from claims that equate their
direction with sink strength.

The driver additionally saves per-cell BOS grids and per-query-position BOS mass. Length mode
also writes 20 normalized position bins.

## 3. One intervention specification system

`InterventionSpec` declaratively represents token-embedding transformations, positional-embedding
transformations, query-bias scale, layer-0 MLP transformations, whole-model MLP skipping, massive
`W_k` edits, and fixed random `W_k` controls. `execute_spec` is the only E5 scientific executor;
the attention, metric, CE, length, content, and parity paths all use it.

| Key | Table label | Specification |
|---|---|---|
| `a` | (a) | Baseline |
| `b` | (b) | Query-bias scale 0 |
| `c` | (c) | Replace PE at position 0 with PE at position 1 |
| `d` | (d) | Swap normalized EPE directions in layer-0 MLP output |
| `e` | (e) | Swap normalized raw-PE directions in layer-0 MLP output |
| `f` | (f) | Zero token embedding at position 0, retaining its PE |
| `g` | (g) | Skip MLP in every layer |
| `h` | (h) | Zero every positional embedding |
| `i` | (i) | Zero the identified massive-coordinate `W_k` columns in every layer |
| `j` | (j) | Zero fixed seeded random `W_k` columns in every layer |
| `b_and_c` | b∧c | Compose b and c |
| `b_and_i` | b∧i | Compose b and i |
| `b_and_d` | b∧d | Compose b and d |
| `b_and_i_and_d` | b∧i∧d | Compose b, i, and d |

Dose specifications are generated from the same registry: `scale_bq_<alpha>` multiplies `b_Q`,
and `interp_pe_<alpha>` sets `PE[0] = alpha*PE[0] + (1-alpha)*PE[1]`.

### Fixed random-Wk control

E5 uses one `random.Random(--random-wk-seed)` draw without replacement. The selected coordinates
are fixed across layers, examples, modes, and data seeds and are recorded in every `run_config`.
This is a deliberate, better-controlled deviation from legacy intervention (j), which resets the
global Python RNG and then draws coordinates inside each layer call. `--verify-parity` strictly
tests a–i and reports j as an intentional semantic deviation rather than pretending equality.

## 4. Implementation and reuse map

- `evaluation_robustness_analysis.py`: E5 specification registry, unified executor, all runners,
  statistics, figures, cache validation, parity, and offline smoke test.
- `intervention_analysis.py`: reuses `manual_self_attention_new`, the legacy `INTERVENTIONS`
  registry for parity, and `compute_band`.
- `residual_sink_analysis.py`: reuses model loading and massive-coordinate identification. Its
  default-preserving `run_config(..., te_transform=None)` and
  `forward_to_logits(..., te_transform=None, pe_transform=None)` now support composition outside
  E5 as well.
- `datasets_loader.py`: adds exact-token long-context concatenation, degenerate content generation,
  and optional FLORES loading. Existing samplers are unchanged.

### Optimized diagnostics path

The existing API already used `compute_diagnostics=False`; E5 does not add a redundant `light`
flag. With diagnostics disabled, manual attention now skips the `Wq@Wk` result vector, top-k
diagnostic work, Q/K clones, pre-mask score clone, cosine loops, sequence-squared Python loop, and
hidden-dimension loop. Existing tuple positions remain stable and contain `None` or empty lists.
The default `compute_diagnostics=True` path used by legacy single-sentence analyses is unchanged.
Attention computation itself is identical.

All E5 evaluation is under `torch.no_grad()`. Only selected-band attention is copied to CPU and is
deleted after metrics are computed. Long-context tensors are deleted per example, followed by
per-seed garbage collection and CUDA cache release.

## 5. E5.1 — Metric multiverse

Default design: GPT-2 small, seeds 0/1/2, 100 examples from each of SST-2, GSM8K, and HumanEval,
exactly 40 tokens, all ten Table-1 interventions. Outputs include raw per-example metrics,
per-cell grids, per-query values, cross-seed mean/SD/SE/95% CI, percent-of-baseline, normalized
effects, Kendall concordance, and intensive/extensive decompositions.

For every intervention, baseline and post-intervention cells are paired by seed, domain, example,
layer, and head. The output reports fitted slope and Pearson correlation, active-to-inactive
fractions at each threshold, and the fraction remaining active while shrinking. Key interventions
b/c/i appear in the scatter panel.

---

## 6. E5.2 — Paired length generalization

Defaults are lengths 40, 128, 256, 512, 1024 and interventions a/b/c/d/i/j. There are 100
examples/domain through 512 and the first 50/domain at 1024. For each seed/domain the sampler:

1. deterministically shuffles source examples;
2. concatenates tokenized examples only within that domain;
3. creates exact 1024-token ID sequences;
4. derives shorter examples as prefixes of the same IDs; and
5. records all source indices and component counts.

The design never decodes and re-tokenizes experimental IDs. Assertions enforce exact lengths.

**Concatenation caveat.** SST-2, GSM8K, and HumanEval generally lack enough naturally long
examples, so 1024-token inputs cross original document boundaries. This preserves domain and token
statistics but does not preserve discourse coherence. It is a transparent evaluation construct,
not a claim about natural 1024-token documents.

### Logit-competition law

For every second-half query, `number_of_valid_positions = query_position + 1`. Probabilities are
clipped only to `[1e-8, 1-1e-8]` before computing `logit(BOS attention)`. Linear slopes against
`log(number_of_valid_positions)` are fit per seed/intervention/domain/length and stored beside the
theoretical slope −1.

### Nested-prefix invariance diagnostic

For baseline passes, the position-0 content key `k0` and per-head
`Delta1 = b_Q dot k0` are saved in the selected band for identical nested-prefix examples. Each
longer length is compared with the shortest prefix using maximum absolute and scale-normalized
relative discrepancy. No comparison is made between independently sampled sequences.

## 7. E5.3 — Functional cost and mitigation frontier

At `--cut-length`, E5 computes next-token CE and sink strength in the same forward for all ten
Table-1 interventions, all four E4 combinations, and both alpha sweeps. Pairing is by seed, domain,
and example. Outputs preserve CE, delta-CE, sink reduction, sink reduction per nat, and domain-level
results. Pareto efficiency uses two objectives: larger sink reduction and smaller delta-CE. A point
is efficient when no other point is at least as good on both and strictly better on one. Negative
and near-zero delta-CE are retained.

Non-finite token losses are marked with `status=nonfinite_ce`; valid token counts and warnings are
saved. No values are imputed. Very large finite No-PE losses remain in raw and aggregate tables.

Per-token profiles cover a/b/c/i at lengths 40 and 1024. The driver saves absolute prediction
positions, normalized positions, ten normalized bins, and early/middle/late region summaries.

---

## 8. E5.4 — Content generality

Controls are derived deterministically from the paired 40-token natural records:

- `random_uniform`: iid IDs from the allowed vocabulary;
- `random_zipf`: iid IDs from the natural sample's empirical unigram distribution;
- `shuffled_natural`: within-example token permutations, preserving multisets;
- `repeat_token`: a deterministic non-special source token repeated to length 40.

The GPT-2 end-of-text ID is excluded from generated tokens. Generation metadata and source pairing
are saved. Domain summaries include raw differences, baseline-normalized effects, cross-seed
uncertainty, sample counts, and paired tests where source pairing exists.

`--with-multilingual` attempts Bangla (`ben_Beng`) and Simplified Chinese (`zho_Hans`) FLORES-200.
Dataset/config/network errors emit a warning, are written as `multilingual_skip_reason`, and do not
abort synthetic or natural domains. FLORES is never touched unless the flag is present.

---

## 9. E5.5 — Statistical upgrades

Bootstrap calibration resamples examples *within each seed and intervention*. It never pools seeds.
The deterministic bootstrap seed is `--random-wk-seed + 1`, repetitions are configured by
`--bootstrap-repetitions`, and output compares bootstrap SE/95% width against empirical cross-seed
SD.

The MDE table uses paired baseline-minus-intervention example differences. A documented
conservative variance is `mean(within-seed paired-difference variance) + variance(seed mean
differences)`. For n = 50, 100, 300, 1000, two-sided alpha .05 and power .80, MDE is
`(z_(1-alpha/2)+z_power)*sqrt(combined_variance/n)`. Both variance components and available pair
count are saved.

### RAM and runtime

Attention is quadratic in length. At 1024 tokens, one 12-head fp32 map is roughly 48 MiB, and a
full 12-layer set would exceed 0.5 GiB before other tensors. E5 retains only the selected band,
moves it to CPU, computes metrics immediately, and releases it. Length mode is the heaviest and
belongs on the 32-GB card. Do not parallelize several 1024-token processes on one GPU without
measuring headroom. Dataset loading and within-domain tokenization also consume host RAM.

## 12. Verification sequence

1. Run the offline smoke test. It constructs a tiny random GPT-2 and synthetic token IDs; checks
   diagnostic/non-diagnostic attention equivalence, strict spec parity where applicable, entropy
   bounds, layer/half indexing, finite CE, all four runners, and six figure families.
2. Run parity on GPT-2 small. Inspect `parity_report.json`; a–i must pass stated tolerances and j
   must be marked `intentional_deviation`.
3. Run the 10-example fidelity command. Compare baseline and b against the established Table-1
   scale without treating approximate historical numbers as assertions in code.
4. Run four full modes, merge caches if necessary, and execute final `--plot-only`.
5. Inspect non-finite statuses, sample counts, exact lengths, invariance discrepancies, and the
   random/massive coordinates in configs before interpreting plots.
6. Run the medium spot-check separately. Do not mix its aggregates with GPT-2 small.

## 13. Suggested paper framing (without results)

E5 can be framed as a robustness audit of a mechanistic claim: whether intervention ordering is
measurement-invariant; whether a fixed source-agnostic logit advantage obeys the predicted
competition law; whether causal sink removal is functionally cheap or costly; and whether the
signature is independent of linguistic content. Report observed estimates and uncertainty only
after real runs. If rankings disagree, slopes differ from −1, intervention damage is non-Pareto,
or synthetic domains drift, those are substantive boundary conditions rather than failed code.
